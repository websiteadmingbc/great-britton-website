# Great Britton Construction — GitHub Pages Website

Static, responsive website with Home, Projects and Reviews pages.

## Publish with GitHub Pages
1. Create a **public** repository named `great-britton-website`.
2. Upload **the contents of this folder** (not the folder itself) into the repository root. You should see `index.html`, `projects.html`, `reviews.html`, and `assets/` at the top level.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Test the GitHub Pages URL before changing your domain's DNS.

## Domain: greatbrittongc.com
**Do not change Weebly DNS or add a CNAME file until the site is approved.** After testing, set a custom domain under GitHub Settings → Pages, and use the exact DNS records GitHub provides. Keep existing MX/TXT/email records intact. GitHub Pages generally requires A records for the apex and a CNAME for www; remove conflicting old website A records only at cutover. Enable Enforce HTTPS once available.
